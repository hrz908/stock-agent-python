# DESIGN.md — 视觉规格（shadcn 风 / 股票工具类小程序）

> 本项目唯一视觉真相源。配套执行文件：`styles/token.wxss`（变量与工具类）、
> `.codebuddy/rules/ui-design-tokens.md`（尺寸令牌规则：字号 / 间距 / 圆角 / 图标）。
> 尺寸档位以规则文件为准；本文负责组件与页面级叙事，两者冲突时先改规则再回填这里。

## 色板（亮色 · 宣纸 · 墨 · 一点青 / 2026-10-27）

> 底色只做底，全站唯一的高饱和色留给涨跌与警告。描边与底色同族，避免异色相发脏。

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | #F2EDE6 | 页面底色（宣纸，饱和度 ≈8%） |
| `--surface` | #FFFFFF | 卡片背景（白纸面） |
| `--surface-2` | rgba(54,49,27,0.12) | 次级背景（用户提问块、快捷提问、禁用态） |
| `--line` | #DCD1CB | 发丝边框 / 分割线 / 图表网格 |
| `--ink` | #36311B | 主文字（暖墨；`--ink-2` / `--ink-3` 同值，层级靠字号与字重） |
| `--primary-fg` | #FFFFFF | 反白文字 |
| `--up` | #dc2626 | 涨（A股红涨） |
| `--down` | #15803D | 跌（加深版绿，白卡 5.0:1） |
| `--flat` | rgba(54,49,27,0.45) | 平 |
| `--color-brand` | #2E6B72 | 黛青强调（按压 #24575C），品牌签名，不与涨红同族 |
| `--color-error` | #DC2626 | 危险 / 错误，与「涨」同一个红 |
| `--color-success` | #15803D | 成功，与「跌」同一个绿 |
| `--color-warning` | #FF9F18 | 需关注（琥珀），事件圆点与标签统一 |

**强调色收口**：全站只允许一个强调色 `--color-brand: #2E6B72`（黛青），且仅用于
**品牌签名 / 链接 / 焦点**（`md-link`、`nickname-link`、`src-link`、`evt-src`、弹窗确认文字）。
**按键与选中态都不用底色**：描边全站只有一个规格 `--hairline`（和输入框同一套），
主次只靠字色与字重。用户提问是一块 `--surface-2` 浅底小块（唯一的浅底块，
因为它是每轮都出现的内容块，不是按键）。强调色不做大面积底色、不做标签底、不做选中底。

**状态色只按语义用**：需关注=琥珀（`--warn` 系，标签与时间轴圆点统一）、
危险=`--danger` 系；常规事件圆点用中性灰（`--ink-3`），不占强调色。
图表数据系列色（`--accent-deep` 条形、均线三色）属可视化标识，不受上述收口约束。

## 深色模式：不启用（终局）

**2026-10-22 晚用户最终决策：只保留浅色，「太暗了」。** 当天曾短暂整站切到
shadcn dark 并截图验收，随后改回浅色，以本文件为准。
原先 `token.wxss` 里的 `page.dark` 变量块已删除，避免死代码误导。
如将来重启深色课题：从 `style/shadcn` 分支历史取回变量，并先解决每个页面
根节点 `theme` class 的注入方式（列表：chat / watchlist / alerts / settings +
分包 kline）—— 不注入 class 变量不会生效；同时 `app.json` 窗口底色与
canvas 侧 5 个 JS 文件的配色都要同步，只改一半会出现「页面浅、图表深」。

## 字号

**档位表以 `.codebuddy/rules/ui-design-tokens.md` 为准，共七档**（2026-10-26 换《设计令牌规范·最终版》）：
24 / 28 / 32 / 36 / 40 / 48 / 64 rpx，**锚点固定为正文 32rpx**（不采用 28rpx 高密度锚点）。
变量统一为 `--font-xs` … `--font-3xl`，页面与组件里不许出现表外字号。

| 语义 | 变量 | 值 | 用途 |
|---|---|---|---|
| 辅助 | `--font-xs` | 24rpx | 角标、版权（本项目最小实际字级是 28，24 基本不用） |
| 次要 | `--font-sm` | 28rpx | 标签、别名行、免责声明、字段说明 |
| 正文 | `--font-base` | 32rpx | 正文、输入、卡内指标、按键（**锚点**） |
| 强调 | `--font-lg` | 36rpx | 卡片标题、按键文案、抽屉导航行 |
| 标题 | `--font-xl` | 40rpx | 页面 / 弹窗标题、焦点数字（**普通页上限**） |
| 大标题 | `--font-2xl` | 48rpx | 空状态主文案、页面大标题 |
| 特大 | `--font-3xl` | 64rpx | 结果页 / 营销数字，一屏只允许一个 |

**焦点数字封顶 40rpx（普通页）**：一张卡只允许一个 `--font-xl` 的大数字，靠 700 字重、`--ink`
主色与留白拿主导权；卡主标题走 `--font-lg` + 700，永远比焦点数字低一档，否则标题与主价
同高、数字失去主导权。`--font-2xl` / `--font-3xl` 只给空状态与结果页，不进卡片内部。
字重走 `--fw-regular / --fw-medium / --fw-semibold / --fw-bold`（400 / 500 / 600 / 700），
字越大字重越轻（大标题用 600 而非 700）。

### 全局字号档位（三档）

设置页「字体大小」写入本地缓存 `font_scale`，各页根节点 `.page` 在 onShow 挂
`font-scale--*` 类，`token.wxss` 在该类下整体平移全部字级变量（custom property
继承进所有子组件，含金融卡）。这是规范第 6.2 条的无障碍缩放例外，
也是唯一允许出现表外字号的场景。

| 档位 | key | 平移 | `--font-xs` | `--font-sm` | `--font-base` | `--font-lg` | `--font-xl` | `--font-2xl` | `--font-3xl` |
|---|---|---|---|---|---|---|---|---|---|
| 标准 | `standard` | 0 | 24rpx | 28rpx | 32rpx | 36rpx | 40rpx | 48rpx | 64rpx |
| 大 | `large` | +4rpx | 28rpx | 32rpx | 36rpx | 40rpx | 44rpx | 52rpx | 68rpx |
| 超大 | `xlarge` | +8rpx | 32rpx | 36rpx | 40rpx | 44rpx | 48rpx | 56rpx | 72rpx |

- 相邻档位差 **4rpx**；旧缓存落在已删除档位（`xsmall` / `small`）时 `utils/font-scale.js` 回退标准。
- 分工固定：**小号 = 标签 / 别名 / 免责声明 / 分节标题；标准 = 正文与卡内所有指标；
  大号 = 按键文案、抽屉导航行、卡片主标题；超大号 = 页面标题与焦点数字**。
- **标签（tag）与别名行（alias）一律用 `--font-sm`**：
  标签 = `.quick-ask-tag`（引导问题维度）、`.chip-text`（K 线周期）、`.evt-type`（事件类型）；
  别名 = 主标题下面说明「是谁 / 什么」的那一行 = `.stock-code`、`.search-item-code`、
  `.alert-card-code`、`.picked-code`、`.drawer-sub`。
  例外：自选页总浮动卡里的涨 / 跌两枚 `.mini-tag` 走**标准**（与同卡其它文字拉平）；
  金融卡副标题行 `.fcard-code` 同走**标准**。
- **免责声明一律 `--font-sm`**：`.page-disclaimer`（自选 / 提醒 / K 线）与对话页
  `.disclaimer`；首屏引导区标题 `.quick-asks-title` 同档。
- **8 张金融卡统一字级**：卡主标题 `.fcard-name` 走 `--font-lg` + 700 加黑；
  副标题 / 别名行 `.fcard-code`（代码、日期·类型、口径）**标准**；卡内指标键、数值、行文案
  （`.fcell-k`、`.fcell-v`、`.flow-*`、`.rep-*`、`.cmp-*`、`.evt-s`、`.quote`）**一律标准**；
  事件类型标签 `.evt-type` 小号；底部说明 `.fnote` 与事件日期 / 来源行同为小号。
  K 线卡图区占位 `.chart--empty`（搜索并选择股票后展示 / 暂无数据）也走标准。
- **逐卡字级例外**（只在各卡 wxss 覆写，共用样式不动）：
  - **行情卡**：主价 `.price` 走 `--font-xl` + 700（卡内唯一大数字，`flex:none` 不参与三等分）；
    涨跌额 / 涨跌幅低一档到标准。
  - **K 线卡**：支撑 / 压力 `.sr-row` 降到**小号**（图区脚注，不与区间指标抢视线）。
  - **资金流向卡**：主力净流入 `.flow-big` 走 `--font-xl` + 700（本卡唯一大数字，与行情卡主价同档）；
    四档拆分、北向持股、龙虎榜仍是标准。龙虎榜三列**等距居中**
    （席位 : 买入 : 卖出 = 1 : 1 : 1，每列约 200rpx，金额 `nowrap` 不折行），
    表头与数据行共用列宽类，上下自动对齐。
  - **同业对比卡**：取消 PE / PB「更低者优」标绿，只有涨跌幅按正负着色
    （绿 = 跌，给低估值标绿会被读成在跌）。
- **聊天页不单独放大一档**：回复正文直接吃全局 `--font-base`，档位是唯一真相源。

侧边抽屉的字级：品牌名 `drawer-title`、四个跳转按键、「新对话」用**大号**；
品牌副标题、导航 / 历史对话分节标题用**小号**；历史会话行用**标准**。全部引用变量。

行高用倍率变量：`--lh-tight` 1.25（单行标题）、`--lh-base` 1.5（正文 / 列表，32 × 1.5 = 48rpx 基线）、
`--lh-loose` 1.6（长文）。数字焦点行可按光学需要微调但不得低于 1.1；
数字一律 `.num`（`font-variant-numeric: tabular-nums`）。新页面只允许引用这三个变量，
不写 26 / 34 / 44 这类裸值。

## 间距刻度（rpx）

只允许九档：**4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96** → `--space-xxs` … `--space-4xl`
（2026-10-26 换最终版后 96 以 `--space-4xl` 回归，专给空状态巨型留白）。

语义口径：卡片内边距 = `--space-lg`（24）、页面左右留白 = `--space-xl`（32）、
栅格 gap = `--space-md`（16）、组件 / 段落间 = `--gap-between`（24）、区块之间 = `--gap-section`（48）、
空状态大留白 = `--space-4xl`（96）。内边距成组用 `--pad-compact`（8×12）/ `--pad-normal`（12×16）/
`--pad-comfortable`（16×24）/ `--pad-page`（0×32），不再逐处手写两段值。
旧的 20 / 28 / 34 三档（栅格 20、卡片 28）已删除，不要再写回来；负 margin 用
`calc(-1 * var(--space-*))`。

## 形状

圆角六档（2026-10-26 换最终版：档名整体下移一位、补 24rpx，像素值不变）：
`--radius-xs` 4（徽章）/ `--radius-sm` 8（标签 / 按键 / 输入框）/ `--radius-md` 12（弹窗内块）/
`--radius-lg` 16（卡片、弹窗面板）/ `--radius-xl` 24（底部弹层、大浮层）/ `--radius-round` 50%（头像、圆点）。
取消 999rpx 胶囊；直角（`border-radius: 0`）只留设置页直框与 chat 首屏引导两处例外。
- 边框统一 `--hairline`（**1rpx** solid `--line`）；虚线用 `--hairline-dashed`
- **浮起面 = `--hairline` + `--shadow-sm`，是一套而不是两件事**：
  卡片、按键、输入框、chips、弹窗按键全部沿用，不按元素另配偏移与透明度。
  纯白页面上只靠边框划块会显得干，加这层刚好托起来。
- 阴影三档：`--shadow-sm`（卡片 / 按键 / 悬浮按钮）、`--shadow-md`（toast / FAB / 吸底输入栏）、
  `--shadow-lg`（弹窗面板 / Modal / 抽屉）。阴影只给「浮起」的元素，页面分区靠留白与 `--hairline`。

## 组件范式

- **行情列表项**：左名称 + 代码两行 / 右现价 + 涨跌幅两行；行高 **112rpx**；
  底部发丝分割线；整列表一张卡，行不单独包卡
- **指标标签**：`--surface-2` 底、全局小号 `--font-sm`、圆角 8、状态色仅作用于文字
- **自选总浮动卡**（watchlist，2026-10-26）：标题「自选总浮动」标准；金额 `--font-xl` 超大号
  （全站唯一的焦点数字）；百分比 · 已同步、刷新、右上角涨 / 跌两枚标签全部标准；
  下方「全部 / 涨幅榜 / 跌幅榜」段控大号；空态主文案标准、补充说明小号；免责声明小号
- **按键**：**一律无填充**，描边与输入框完全一致（`--hairline`，不写黑色/红色描边）；
  形状统一 `--radius-sm` 圆角（8rpx），高度 ≥96rpx（= `--space-4xl`）。主次只靠文字——主动作 `--ink` + 600，
  次动作 `--ink-2` + 400，危险动作用 `--danger` 字色。
  **按键文案统一全局大号 `--font-lg`**（2026-10-26）：底部主行动点（添加股票 / 新增提醒 /
  退出登录）、弹窗的取消与确认、聊天页语音键「点击聆听」（另加 600 加粗）、抽屉「新对话」，
  都吃同一档，不再按位置各写 body。
- **弹窗字级**（`base-popup`，2026-10-26）：标题 `.popup-title` 走全局大号 `--font-lg`；
  表单字段名 `.form-label`（股票代码 / 买入单价 / 持股数量…）与提示区
  （`.note-title` / `.note-row`，如交易所代码前缀）走小号 `--font-sm`；
  输入框内容与 placeholder 走标准 `--font-base`。
  整屏不出现黑块 / 红块按钮，也不出现「浅底药丸」；chips 与段控的选中态
  只提字重与字色，不加底色、也不加深描边。输入框同理：描边而非浅底
- **直角框体**（`settings` + `chat` 首屏）：设置页的字体大小段控与「隐私说明」入口**同款**——
  `border-radius: 0`、96rpx 等高、`--hairline` + `--shadow-sm`，上下两块仅内部分布不同
  （段控三分等宽居中，入口行左右两端）；`chat` 首屏「引导问题」三条（`.quick-ask`）同样走直角。
  直角只在这两处，不外溢到其它页
- **AI 回复**：**不包气泡**。白底页面上再套一层描边气泡是纯噪音；回答直接排版，
  左侧挂 1rpx `--line` 页边线（全站唯一的「页边线」例外），轮次之间用 `--space-2xl`
- **AI 加载态**：**全轮只有一处**，占在回答该出现的左侧（同一条页边线、同 `--space-lg` 缩进）。
  结构＝三个点 + 一句主文案（`--font-base`、`--ink`、500）；第二行说明用
  `--font-sm` + `--ink-3`，**只在耗时较长时出现**，平时不占高度。
  文案随真实阶段推进（理解 → 检索 → 取数 → 整理 → 长耗时 → 重连），
  阈值 1.6s / 12s / 26s，文案表见 `chat.js` 的 `LOAD_COPY`：只写在做的事，
  不承诺剩余时间。动效只走透明度与缩放，页边线在 `--line` 与 `--ink-3` 之间呼吸；
  断线重连时动效停下、主文案转 `--warn`（等的是网络不是模型）。
  **正文开始后不再有独立「生成中」条**：改用正文末尾光标（4rpx × 32rpx），
  只在服务端停顿时才在光标后补一句说明
- **用户提问**：右对齐、`--surface-2` 浅底小块、`--ink` 正文字。
  **不用近黑实底**——每次提问都是一块黑，会把视线从回答上拽走
- **免责声明**：纯文字小号 `--font-sm`，无框无底；每屏都在的固定元素，越安静越好
- **首屏引导**：空会话（没有任何消息、也不铺问候语）时，下方给三条可点问题（`--surface-2` 底、
  88rpx 高、右侧箭头），点一下等同发送
- **概览宫格**（alerts）：两格共用一张卡 + 中间竖分割线，标签在上、数字在下；
  不要并排两个独立框。字级（2026-10-26）：标签（全部提醒 / 今日触发）标准、
  数字大号 `--font-lg`；分组标题「价格与涨幅提醒」标准
- **侧边抽屉**（chat）：品牌头部 → 导航行（**只有文字 + 右侧箭头，左侧不放图标**，
  文字走 `--font-lg` + 500；不套分组外框，但上面加「导航」小标题，
  与「历史对话」同款 `--font-sm` + 600；标题上间距为 0，靠头部已有的 `--space-xl` 分隔）
  → 历史对话（行间留 `--space-md` 间距，
  当前会话套 `--radius-sm` 方框）→ 新对话按钮**钉死在底部**，
  `--radius-sm` 方角，与打字输入栏**同高度且同一水平线**：两者内边距 / 描边 /
  内容高度（88rpx）完全同构，底部都让出 `padBottom` 安全区，少一样就会错开半条边。
  **只有历史对话这一块自己滚**，头部与导航固定不动。
  切换 / 删除历史会话都在原地完成：**不跳页、不收起抽屉**
  （删掉当前会话时原地换一条新空会话），用户始终停在抽屉上
- **二次确认一律走 `base-popup`**：抽屉里的「删除对话」也用这套弹窗，
  **不用**原生 `wx.showModal`——两端样式不一致，也不跟主题走
- **输入栏**（chat）：两端各一个带圈按钮——左端模式键（麦克风 / 九宫格），
  右端发送键，圆圈描边与投影同规格，视觉上左右对称。
  **语音态不改输入栏样式**：同一条白底描边输入栏，只换内容——左端换成网格图标（`AppstoreOutline`，
  antd 没有键盘图标，九宫格与键位是同一套视觉语言，别用铅笔）、中间语音键、
  右端发送键只留图标（圆圈去掉，聆听中才提到正文字色）
- **语音输入**（chat）：**点一下开始、再点一下发送**，不用「按住说话」
  （按住时会话区被手指压住，松手即发也不好改口）。聆听中：输入栏显示
  「聆听中 · 再点发送」，上方浮出**预输入文字框**（波形 + 实时转写 + 取消），
  终稿直接发给 agent，不再落回输入框等二次确认
- **空状态**：线性图标 `--icon-xl`（56rpx，图标档上限）灰 + 一句主文案 + 一句下一步动作（`sub`），**禁止 emoji**
- **导航**：88rpx 高 + `env(safe-area-inset-top)`；标题视口绝对居中
- **tabbar**：本项目 `app.json` 未配置 tabBar（页面切换不走 tabbar），
  原手册阶段 4 的 tabbar 改色条目对本项目**不适用**

## 图标

- **统一用自研 `components/base/icon`**：用到图标的页面/组件在 json 里声明
  `"base-icon": "/components/base/icon/icon"`，WXML 写 `<base-icon type="..." />`。
  不再依赖 antd-mini 整包（原先仅为了 Icon 就要背 2.5MB 依赖链），
  但字形仍是 antd-mini 3.4.3 的官方 TTF，视觉与旧版一致。
- **尺寸与颜色写在 style 上，尺寸只取图标档**：`style="font-size:var(--icon-base);color:var(--ink);"`。
  图标只有五档 `--icon-xs` 28 / `--icon-sm` 36 / `--icon-base` 40 / `--icon-lg` 48 / `--icon-xl` 56，
  纯图标按钮的可点区域不小于 `--icon-touch`（88rpx）。
  组件的 `.ico` 只设 `font-size: inherit`——字号靠宿主节点继承进来，
  组件里再写死一个字号会把调用方的尺寸全部盖掉。
- **可用图标**：`components/base/icon/icon.wxss` 的 `.ico-*` 码点表（当前 18 个，
  覆盖全站实际用到的图标）。新增图标时从 antd-mini 的 `Icon/index.wxss`
  取对应 `content` 码点补一行，同时确认字体里确实有这个字形。
- **字体**：`styles/antd-icon.wxss` 里 base64 内联（网络字体在 iOS 上不可靠，
  加载失败会整屏豆腐块），由 `app.wxss` 全局引入，是唯一的 `@font-face`。
  换字体文件时同步改 `icon.wxss` 的码点表。

## 导航与返回（子页面退回主页）

- **主页**：`pages/chat/chat`（唯一根页，含抽屉导航）。
- **页面切换方式**：子页面一律由主页 `wx.navigateTo` 进入（抽屉项 / 行情卡 /
  自选股行点击），**不**走 tabBar、不 `redirectTo`，故每个子页都有「上一页」可出栈。
- **返回入口（统一交互）**：所有子页顶部用 `base-navbar` 的 `left-arrow`
  + `bind:back`，点击触发本页 `goBack`（kline 为 `onBack`）出栈返回。
- **返回逻辑（统一写法，四处一致）**：

  ```js
  wx.navigateBack({ fail: () => wx.reLaunch({ url: '/pages/chat/chat' }) });
  ```

  优先 `navigateBack` 出栈回上一页；若栈为空（被单独拉起 / 栈被清）则
  `reLaunch` 兜底回主页。**禁止** `switchTab` 兜底——`chat` 不是 tabBar 页，
  `switchTab` 必然失败，会让兜底也失效。

- **各子页返回路径**：

  | 子页 | 标题 | 进入来源 | 返回目标 |
  |---|---|---|---|
  | `pages/watchlist/watchlist` | 自选股 | 主页抽屉 | 主页（chat） |
  | `pages/alerts/alerts` | 提醒 | 主页抽屉 | 主页（chat） |
  | `pages/settings/settings` | 我的 | 主页抽屉 | 主页（chat） |
  | `pages/privacy/privacy` | 隐私说明 | 设置页「隐私说明」 | 上一页（settings）；栈空时兜底回主页 |
  | `pages/kline/kline` | 各周期 K 线 | 主页抽屉 | 主页（chat） |
  | `pages/test/index` | 卡片画廊（**仅开发版**） | 主页行情卡 **或** 自选股行 | 上一页；非开发版 `onLoad` 直接 reLaunch 回主页 |

  除主页外都是二级子页，`navigateBack` 回其上一页符合层级直觉；`reLaunch`
  兜底保证极端情况下仍能回到主页，不会出现卡死 / 空白页。

## 排版八条（结构与居中专章）

1. 垂直居中唯一写法：flex + `align-items:center`。禁止用 line-height 撑高居中
   （导航标题不居中基本都病源于此）。
2. 水平居中唯一写法：flex + `justify-content:center`，纯文本用 `text-align:center`。
   禁止 `margin:auto` 猜宽度。
3. 导航栏标准：height 88rpx + `padding-top: env(safe-area-inset-top)`；
   title 视口绝对居中（有返回按钮时 `position:absolute` + `left:50%` +
   `translateX(-50%)`，禁止排布居中导致标题跳动）。
4. 文字防溢出三件套：`overflow:hidden` + `text-overflow:ellipsis` +
   `white-space:nowrap`；多行用 `-webkit-line-clamp`。名称 / 标题字段必须带三件套。
5. 数字右对齐列：价格 / 涨跌幅 / 市值统一定宽 + `text-align:right` + 等宽数字；
   名称列 `flex:1` + `min-width:0` 左对齐；数字必须竖向成线。
6. 间距不重叠：相邻元素垂直间距取 max 不取 sum；容器统一 padding，
   子项间用 gap 而非互相 margin。
7. 点击热区 ≥ 88rpx × 88rpx，小图标用 padding 撑热区。
8. 基线节奏：分割线 / 边框统一 `--hairline`；同列表行高统一
   （行情 112rpx，普通 96rpx），禁止逐行自定。

## 禁止清单

- wxss 硬编码 hex / rgba / 表外 rpx（字号、间距、圆角、图标一律 `var(--*)`）
- 渐变背景、重阴影、彩色分割线；卡片 / 标签圆角超过 `--radius-lg` / `--radius-sm`
  （按键与输入框走 `--radius-sm`，不在此限）
- emoji 当图标；同屏超过 2 种强调色（涨跌色按语义不计）
- 给按键加填充底色：主行动也不填，靠 `--hairline` 描边表达（添加 / 新增 / 确认 / 发送一律如此）
- 给按键写黑色 / 红色描边：描边规格全站只有 `--hairline`，和输入框完全一致
- 给输入框铺浅底（`--surface-2`）代替描边——和按键同一套描边语言
- 自造字号 / 间距 / 圆角 / 图标档位（例如 26 / 30 / 34 / 38rpx 字号、20 / 28 / 34rpx 间距、999rpx 胶囊；
  96rpx 现为 `--space-4xl`，只给空状态巨型留白）
- 给浮起面手写裸 `box-shadow`：卡片 / 按键 / 输入框 / 弹窗按键一律引用 `--shadow-sm`，
  浮层 `--shadow-md`，弹窗面板 / Modal `--shadow-lg`，不要在具体规则里另配偏移与透明度
  （否则全站深浅不一）
- 只给描边不给投影、或只给投影不给描边：两者是同一个「浮起面」（见「形状」）
- 给 AI 文本回复再包一层气泡/描边容器（见「组件范式 · AI 回复」）
- 把 AI 加载态做成彩色底 / 渐变条 / 骨架屏，或同时挂「思考气泡 + 底部状态条」两套动效
  （见「组件范式 · AI 加载态」）
- 同一屏出现两个 `--font-xl` 焦点数字（上限档的唯一性就是它的全部作用）
- 拿带符号的 `fmtPct` 渲染无方向指标：毛利率 / 净利率 / ROE / 股息率 / 振幅 /
  北向持股比例一律用 `fmtPctPlain`，`fmtPct` 只给涨跌幅与同比这类真有方向的数字
- 在数值节点上再写 `color: var(--ink)`：会以「后定义者胜」盖掉 `.up` / `.down`，
  涨跌着色整片失效（资金流四档、同业对比表都踩过）

## 项目专属约束（原手册未覆盖，务必遵守）

1. **canvas 双轨**：uCharts（kline 页、kline-card、sparkline）不吃 CSS 变量，
   配色在各自 `.js` 里另写一份。改本文件色值时必须同步那批 JS 硬编码，
   否则「页面换肤、图表没换」。
2. **组件样式隔离**：`components/**` 默认隔离，`styles/token.wxss` 里的
   **自定义属性能透传**、**工具类 class 不透传**。给组件内部节点用工具类，
   需在组件自身 wxss 内复写，或组件 json 设 `styleIsolation`（属结构调整，需同时更新本文件与令牌规则）。
3. **WXSS 是 CSS 受限子集**：禁 `*` 通配符、禁 `:hover/:active`（按压走 `hover-class`）、
   禁 `@media` / `rem` / `vh` / `vw`、单位统一 rpx（安全区对齐处除外）。
4. **涨跌语义类**：涨跌平一律用 `.price-up` / `.price-down` / `.price-flat`，
   不要再按 `--up` / `--down` 逐处写 color。
5. **输入栏的语音态**（chat）：输入栏不做整条变色，因此**不要**再引入
   `.sender-bar::after` 那类全宽扫入层——它同色系叠在文字上会让「按住说话 / 聆听中」
   整片消失，且逼出一串 z-index 补丁。换内容（文字 + 图标）而不是换底色。
   左端模式键的两态内容**常驻 DOM**、用 opacity 交叉淡入（`wx:if` 换节点是销毁重建，
   会闪）；中间输入区与语音键是互斥节点，**禁止挂进场淡入**——每次切换都会重播，
   那正是肉眼看到的「闪一下」。
